# WCAG, Section 508, and ADA — which name to use

This orientation page now lives at [source/docs/which-name.html.md](source/docs/which-name.html.md) (site: `/docs/which-name/`).

**WCAG** is the technical standard. **Section 508** is a U.S. federal ICT law that *uses* WCAG 2.0 AA. **ADA Title II** uses WCAG 2.1 AA for state and local web and mobile apps.

Start with [source/docs/profiles/requirement-profiles.html.md](source/docs/profiles/requirement-profiles.html.md).
