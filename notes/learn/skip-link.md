# Skip past repeated blocks

Published: `source/learn/skip-link.html.md` → `/learn/skip-link/`

Draft mastery: The learner can add a working skip link to a page with a long header, or point at a missing one.

Live specimens use a unique target id inside `<main>` (not `id="main"`, which the page already has). Nested `<main>` is invalid, so the isolated good is a skip plus a `#article` (or similar) target.
