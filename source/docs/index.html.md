Copies and structured extracts of official accessibility sources, kept in markdown so humans and agents can read them offline.

Every file starts with a **source block**: official URL, document status, and license. W3C material is copied under the [W3C Document License (2023)](https://www.w3.org/copyright/document-license-2023/). U.S. government material is generally in the public domain. See [LICENSE-NOTES.md](LICENSE-NOTES/) and [SOURCES.md](SOURCES/).

**These local files are not the official specifications.** Use the dated official URL when you need a referenceable standard.
