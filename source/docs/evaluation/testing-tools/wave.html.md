Official: [WAVE](https://wave.webaim.org/), [WAVE browser extensions](https://wave.webaim.org/extension/), [WAVE Help](https://wave.webaim.org/help). WAVE is © WebAIM.

WAVE injects icons into the rendered page so you can see errors, alerts, features, and structure (including headings) on top of the layout.

The **website** form at wave.webaim.org cannot reach a page on your computer (`localhost`). For a local site, use the **extension**.

## Install

Official hub (Chrome, Firefox, Edge): https://wave.webaim.org/extension/

Chrome / Chromium store listing: [WAVE Evaluation Tool](https://chromewebstore.google.com/detail/wave-evaluation-tool/jbbplnpkjmmeebjpijfedlgcdilocofh).

Open the listing in Chrome or Chromium and add the extension.

## Scan a page

1. Open the page under test. On this site’s isolated examples, close **Edit**.
2. Click the WAVE toolbar icon (or the page context menu item, if present).
3. Read the overlay. Icons are a prompt for a person, not a pass/fail certificate.

## What it is not

Not Trusted Tester. Not a substitute for [axe](axe/) (overlay vs rule list) or for a [screen reader](screen-reader/).
