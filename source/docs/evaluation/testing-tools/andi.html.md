Official install and help: [ANDI — install](https://www.ssa.gov/accessibility/andi/help/install.html) (U.S. Social Security Administration).

ANDI is a free bookmarklet. It inspects accessible names, descriptions, headings, and related properties on the current page. DHS **Trusted Tester v5** uses it. See [DHS Section 508 Training](../../../definitions/dhs-508-training/) and the definition of [ANDI](../../../definitions/defined-terms/#andi).

## Install

Install from SSA’s page (drag the bookmarklet to the bookmarks bar). This site does not host the script.

https://www.ssa.gov/accessibility/andi/help/install.html

On some work or government computers you need IT approval first; that can take time.

## Scan a page

Open the page under test. On this site’s isolated examples, close **Edit**, then run ANDI from the bookmark.

## Try it on this site

[Do not skip heading levels](/learn/heading-order/) has live bad and good pages. Other leaves: [knowledge tree](/learn/).

## What it is not

Installing ANDI does not make you a Trusted Tester. Agencies that adopt that process accept results only from **certified** testers. ANDI is the inspection tool in that process, not the process itself.
