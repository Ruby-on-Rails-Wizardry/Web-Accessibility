Working vocabulary for this library. **Do not invent definitions.** Use the official term lists below, and take the DHS Section 508 Training courses when you need the tester/author/PM framing.

## Start here

- [DHS Section 508 Training](dhs-508-training/) — free courses for “What Is Section 508,” Trusted Tester, accessible documents, and IT project managers. **Reference:** [https://www.dhs.gov/508-training](https://www.dhs.gov/508-training)
- [Defined terms](defined-terms/) — Access Board E103.4 (binding 508 vocabulary), GSA program terms, WCAG glossary pointer

## Which list is which

| List | Publisher | What it is |
| --- | --- | --- |
| [E103.4 Defined Terms](https://www.access-board.gov/ict/#E103-defined-terms) | U.S. Access Board | Normative vocabulary in the Revised 508 Standards (ICT, authoring tool, name vs label, …) |
| [WCAG 2.2 Glossary](https://www.w3.org/TR/WCAG22/#glossary) | W3C | Normative vocabulary *inside* the success criteria (incorporated by 508 as WCAG 2.0; ADA Title II uses 2.1) |
| [Glossary of Section 508 Terms](https://www.section508.gov/tools/glossary/) | GSA | Program, acquisition, and testing language (ACR, VPAT, ANDI, Trusted Tester, ICT Testing Baseline) |
| [Commonly Used Acronyms](https://www.section508.gov/tools/acronyms-abbreviations/) | GSA | Abbreviations used on Section508.gov |

When a term appears in more than one list, **the standard that binds the work wins**: E103.4 for a 508 conformance argument; the WCAG glossary for a WCAG success criterion; GSA for how federal programs talk about testing and procurement.
