DHS offers **free** online training to create and test digital content that is accessible. The courses cover design and production with built-in accessibility and human-centered design, so deliverables can meet Section 508 while also improving usability.

Create an account and take the courses on the [DHS Customer Experience Directorate (CXD) Training Portal](https://training.section508testing.net/). Additional customer-experience material: [DHS CX Training Resources](https://www.dhs.gov/cx/learning-trainings/cx-learning).

This page is a map of the catalog. **It is not a substitute for the courses**, and it is not a certification.

## What Is Section 508 and Why It Is Important

Prerequisite for the other Section 508 compliance courses. You must take this course before the others.

| | |
| --- | --- |
| What it covers | Why Section 508 exists: making ICT accessible to people with disabilities; job responsibilities; resources for meeting the requirements |
| Audience | Section 508 Coordinators, Trusted Tester candidates, IT personnel (including project and program managers and instructional designers), leadership, CIOs, procurement and acquisition officers, and web developers |
| Duration | Unlimited |
| Delivery | Web-based, self-paced |
| Prerequisites | None |
| Registration | [Training portal](https://training.section508testing.net/) |

The program also describes **twelve plays** for integrating strategic, business, and technology management into a Section 508 program. The **DHS Section 508 Playbook** itself is available only to DHS personnel.

## Trusted Tester for Web Certification Program

Earn Trusted Tester Certification for Web. You learn the **Trusted Tester Section 508 Conformance Test Process for Web** and use it to test websites and web applications against the Revised Section 508 Standards. Certification requires **85% or higher** on the Trusted Tester Certification Exam.

| | |
| --- | --- |
| Audience | Trusted Tester candidates, program managers, developers, system owners |
| Duration | **180 days** (6 months) to complete the program |
| Delivery | Web-based, self-paced |
| Prerequisites | None. Courses must be completed **in order** |
| Registration | [Training portal](https://training.section508testing.net/) |

The program walks, in order:

1. The “What Is Section 508” orientation (same prerequisite as the other programs).
2. Which Revised 508 Standards apply to web and web applications.
3. Installing the Trusted Tester tools. This step **may need IT support and administrative access**; on government equipment it can add weeks.
4. Using the test process, with an incremental exam.
5. A practice exam on sample pages. Score **85% or higher** to sit the certification exam.
6. The certification exam: test web pages with the Trusted Tester process; **85% or higher** to certify.

DHS describes Trusted Tester as a **code-inspection** test approach that is more consistent than relying on assistive technology or automated tools alone, so the site or software works with the assistive technology a person actually uses. The process follows the [ICT Testing Baseline for Web](https://ictbaseline.access-board.gov/web-baselines/). Some test steps are Trusted Tester–specific and are marked in reports.

Official process and tools (live; not copied here):

| Resource | URL |
| --- | --- |
| Trusted Tester Conformance Test Process (GitHub) | https://github.com/Section508Coordinators/TrustedTester5.1 |

Agencies that adopt Trusted Tester accept results only from **certified** Trusted Testers.

## Section 508 IT Project Manager Program

Guidelines for Contracting Officer Representatives (CORs) and program and project managers so IT teams address Section 508 in each stage of the acquisition life cycle: requirements, procurement rules, contract language, scoping, and Section 508 artifacts.

| | |
| --- | --- |
| Audience | Anyone who manages or plans programs or projects at DHS, or who integrates life-cycle processes including accessibility and Section 508 |
| Duration | Self-paced |
| Delivery | Web-based |
| Prerequisites | None (the orientation course is still listed in the program) |
| Registration | [Training portal](https://training.section508testing.net/) |

The program includes the Section 508 orientation and a basic overview of the federal acquisition process for procuring ICT that conforms to Section 508.

## What this is not

- It is **not** WCAG-EM. WCAG-EM is W3C’s evaluation methodology ([local page](../evaluation/wcag-em/)). Trusted Tester is a federal **508** test process aligned to the ICT Testing Baseline.
- Completing training does not by itself make a product conform. Conformance is still the Revised 508 Standards (electronic content: WCAG 2.0 A + AA via E205.4).
- This library does not host the courses, the exam, or ANDI.
