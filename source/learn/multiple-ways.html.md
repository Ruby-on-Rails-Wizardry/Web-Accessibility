title: More than one way to find a page
description: A set of pages needs more than a single nav path. Search, a sitemap, or a related-links list is the second way.

If the only way to reach a page is one deep menu, people who cannot use that menu are stuck. **2.4.5** asks for **two** ways within a set of pages (nav + search, nav + sitemap, …).

A step in a **process** (checkout) is excepted — you are not required to offer a second way into “enter CVV.” [Skip past repeated blocks](/learn/skip-link/) is a different criterion (bypass on one page).

Section 508 **excepts non-web documents** from 2.4.5 (E205.4). Web sites are in.

Hooks: **2.4.5 Multiple Ways**. Official pair: Sufficient [G125](https://www.w3.org/WAI/WCAG22/Techniques/general/G125), [G161](https://www.w3.org/WAI/WCAG22/Techniques/general/G161), [G185](https://www.w3.org/WAI/WCAG22/Techniques/general/G185). Understanding: [Multiple Ways](https://www.w3.org/WAI/WCAG22/Understanding/multiple-ways).

## Contrast

**Worse:** Department pages exist only as items in a hover mega-menu. There is no search and no A–Z list.

**Better:** The same menu, plus site search that returns those pages (or a sitemap that lists them).
