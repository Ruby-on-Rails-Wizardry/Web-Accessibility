A profile is a named bar for this library:

- `section-508-web` / `section-508-nonweb`
- `ada-title-ii`
- `wcag-22-aa` (and A / AAA / EN when you mean them)

Use one name in the first message to an agent, or as the covering set for a demonstration. Mixed obligations: take the **stricter union** and label extras so a 508 report is not polluted with 2.2-only findings.

Cards, official cites, and catalog columns: [Requirement profiles](/docs/profiles/requirement-profiles/). How to work a thin slice: [Reducing cognitive load](/docs/agents/reducing-cognitive-load/).

This node is orientation. It still traces to [equal worth](/learn/equal-worth/): the profile is *which techniques we require*, not *whether the person matters*.
