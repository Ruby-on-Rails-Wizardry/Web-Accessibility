This is a **family**, not one cop. People memorize where “Search” and “Help” sit. Moving them, or calling the same action “Submit” on one page and “Send” on the next, breaks [predictable](/learn/pour/) use.

- [Repeated navigation stays in order](/learn/consistent-nav-order/) — **3.2.3**.
- [The same action keeps the same name](/learn/consistent-identification/) — **3.2.4**.

Then: [Help stays in the same place](/learn/consistent-help/) (WCAG 2.2).

Section 508 **excepts non-web documents** from both 3.2.3 and 3.2.4 (E205.4). Web content is in.
