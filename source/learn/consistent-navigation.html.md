People memorize where “Search” and “Help” sit. Moving them, or calling the same action “Submit” on one page and “Send” on the next, breaks [predictable](/learn/pour/) use.

This node covers two AA criteria that travel together:

- **3.2.3 Consistent Navigation** — repeated nav in the same relative order (unless the user changes it).
- **3.2.4 Consistent Identification** — the same function has the same name / identification.

Section 508 **excepts non-web documents** from both (E205.4).

Official pair: Sufficient [G61](https://www.w3.org/WAI/WCAG22/Techniques/general/G61), [G197](https://www.w3.org/WAI/WCAG22/Techniques/general/G197). Understanding: [Consistent Navigation](https://www.w3.org/WAI/WCAG22/Understanding/consistent-navigation), [Consistent Identification](https://www.w3.org/WAI/WCAG22/Understanding/consistent-identification).

## Contrast

**Worse:** Header order is Home / Permits / Contact on one page and Contact / Home / Permits on the next. A printer icon is “Print” in one view and “Download PDF” in another for the same action.

**Better:** The same items in the same order. The same action keeps the same accessible name.
