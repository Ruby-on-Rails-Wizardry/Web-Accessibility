title: Which name to use
description: WCAG is the technical standard. Section 508 and ADA Title II use WCAG. Those names are not interchangeable.

---

People say “508,” “ADA,” and “WCAG” as if they were one bar. They are not.

| What people say | What it actually requires (typical) |
| --- | --- |
| 508 | Revised 508: **WCAG 2.0 AA** for electronic content, plus ICT chapters |
| ADA Title II / the web rule | **WCAG 2.1 AA** for state and local web and mobile |
| WCAG 2.2 AA | Current WCAG 2 Recommendation; meets 2.1 and 2.0 as well |

The full orientation, with official URLs, is in the library: [Which name to use](/docs/which-name/).
