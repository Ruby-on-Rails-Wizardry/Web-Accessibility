# Originals (not in git)

Copyrighted PDFs stay off the public remotes. Fetch them onto this machine when you want the page images.

## Learning for Mastery (1968)

```bash
# from the repo root
mkdir -p docs/learning/originals
curl -fsSL -A "Mozilla/5.0" \
  -o docs/learning/originals/ED053419-learning-for-mastery.pdf \
  "https://files.eric.ed.gov/fulltext/ED053419.pdf"
```

- ERIC record: https://eric.ed.gov/?id=ED053419
- 13-page scan of the RELCV reprint (12-page article + covers)
- Personal / fair-use copy only. Do not commit or redistribute.
